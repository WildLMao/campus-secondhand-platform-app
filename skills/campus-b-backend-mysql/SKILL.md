# B · 后端、MySQL 与接口协议

先读[共同协作约定](../协作约定.md)和[协作包入口](../../README.md)。本 skill 中的源码、配置及新增 `docs/` 路径均相对包内 `reference-app/`；需求编号以包内 `requirements/documents/软件工程课程需求报告.md` 为准。目标是让交付环境真实使用 MySQL，提供与 C 约定的接口，并修复 D 复现的后端规则问题。替换连接地址不是完整交付。

## 先读哪些内容

读取后端 `pom.xml`、`application.yml`、`schema.sql`、`SqlMapper.java`、`Store.java`、`MarketService.java`、`ApiController.java`、`AssetController.java`、`WebConfig.java`、`SeedData.java` 及现有测试。按任务读取 FR01—24、BR01—20、订单和物品 ST，以及 AC-D-01—12。

与 C 一起检查 `frontend/src/api.js`、`App.vue` 的实际消费方式；与 A 对齐 Compose、环境变量和数据库生命周期。按需拆分后端服务与控制器，先保持接口行为，再修改规则，避免将重构和规则变化混在一批。

## 数据库替换

- 在真实 MySQL 8.4 建立测试库，核对 UTF-8 字符集及排序规则、大小写行为、字段长度、DECIMAL 金额、UTC 时间保存、唯一约束和查询索引。
- 让交付/部署配置明确选择 MySQL；是否保留 H2 作为可选开发配置在交接中写清，不能 MySQL 连接失败后静默回退 H2。
- 先盘点 H2 数据是否需保留。一次性演示数据可在确认后重新初始化；需保留则迁移账户密码哈希、物品版本、订单快照、占用、回执和关联记录，并同步图片文件。不能只迁移订单主表。
- 区分空库初始化与后续结构升级，提供可追踪的版本化迁移脚本和执行顺序，不依赖每次启动的 CREATE TABLE IF NOT EXISTS 完成升级。
- 验证隔离级别和锁语义；当前约定为 READ_COMMITTED，账户按 ID 排序，再锁物品和订单。所有相冲突写入路径遵循一致的锁顺序，处理死锁/超时时不重用失败事务。
- SqlMapper 中动态 SQL 只能来自服务端固定语句，用户输入须使用参数绑定，不能把请求中的 SQL、排序字段或表名直接拼入。

## 接口契约与模块边界

以当前 `/api` 为起点，维护项目 `docs/api/` 下的契约，优先使用 OpenAPI；初期可先写清接口表及请求响应样例。B 维护、C 核对消费、D 核对业务，避免各人各持一份不一致的协议。

契约必须明确：方法和路径、身份/归属、请求字段与校验、响应及空值、HTTP 状态与业务错误、分页、金额和时间、图片标识、Session/CSRF、Idempotency-Key 的生命周期及内容冲突语义。数据表改名不应迫使前端修改；通过 DTO 明确返回字段，不能直接公开敏感实体。

B 负责全部后端业务入口，包括治理导致的订单变化；争议受理/结案与订单状态转换通过统一服务协作。公共资格判断按动作区分新业务和旧单权利，不能用“受限账户一律拒绝”的全局拦截替代。

## 必须保持的交易规则

1. 身份与归属先检查，再识别重复；仅新意图重查新交易条件。同意图关键内容变化拒绝，旧回执不得因后续封禁/占用被改写。
2. 订单、快照和唯一占用共同成立，失败无残留；唯一占用针对有效订单，不能禁止同物品存在多笔历史订单。
3. 卖方登记后待买方确认，只有该买方本人确认才成交；管理员不能代确认，重复操作不重复计数。
4. 普通取消检查阶段、登记、争议及未交付声明。已报告交付或陈述冲突须阻止普通取消；与登记竞争时只有相容结果成立。
5. 隐藏、封禁、争议是独立限制/标记，不覆盖生命周期。取消、解封、解除隐藏不能绕过其他条件恢复可售。
6. 争议保留原阶段和占用，暂停接单、拒单和交付登记；已登记时允许买方本人确认。异常终止释放占用但不自动重售，核实归属后显式重发并重审。
7. 保留受限旧单处理、终态会话只读、历史快照不可回写、终态举报不重开订单、通知失败不撤销交易结果。

## 测试、交付与修复

在真实 MySQL 上验证正常闭环、两个买方竞争、同意图并发/响应丢失重试、取消与登记竞争、版本审核冲突、限制与旧单、争议恢复/终止、隐私和统计去重。使用独立连接和同步发起机制验证并发，不把顺序调用标为并发。

提供安全的管理员初始化方式；关闭演示种子不应造成无法管理的空库，不把固定演示密码当正式初始化。凭据从指定的运行配置读取，不提交真实秘密。

交付后端代码、数据库初始化/迁移、接口契约、MySQL 测试环境与执行结果。D 提出问题后复现、修复、补回归测试并回填修复版本，交 D 用原反例复验。B 自测不能代替 D 的独立验收。
